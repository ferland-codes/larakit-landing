Powerful Features

LaraKit is packed with all the tools, security features, and integrations you need to build and scale your SaaS in record time.

Modular Architecture

Premium Extension Modules

Seven production-ready modules, installed on-demand straight from your terminal. Each ships with migrations, seeders, permissions, routes and views — zero boilerplate.

Extension

Storage Manager

Dual-instance file explorer with complete Private and Public storage isolation.

  • 1 GB storage quota & 512 MB file limit.
  • Recursive ZIP archiving & extraction.
  • Folder color tags and soft-delete trash.
  • In-browser PDF and image previews.
php artisan larakit:install storage
Extension

Email Manager

Gmail-like interface with SMTP mail delivery and two-way IMAP sync.

  • Socket-level connection (no php-imap extension).
  • Flag changes propagate back to server.
  • Rich Text editor with To/Cc/Bcc.
  • Encrypted credentials & connection tests.
php artisan larakit:install email
Extension

AI Assistant

RAG-augmented AI chat platform supporting top LLM cloud & local models.

  • Key rotation & cooldown failovers.
  • Document knowledge base indexing.
  • Curated vs Uploaded conflict handlers.
  • Floating widget chat component.
php artisan larakit:install ai
Extension

Notification Center

Unified multi-channel alert delivery service with manual dashboard send.

  • DB, Email, SMS, WA, Telegram, FCM, Web Push.
  • Reusable HTML email structures.
  • Targeting groups with subscriber lists.
  • Live delivery logs and dispatch helpers.
php artisan larakit:install notification
Extension

WhatsApp Gateway

Self-hosted Baileys Node.js WhatsApp session and QR pairing server.

  • Direct API dispatch (no subscription fees).
  • AI Auto-Reply with typing indicators.
  • PID locks block flapping/440 conflicts.
  • Anti-ban sending queues with jitter delay.
php artisan larakit:install wagateway
Extension

Report Builder

No-SQL report customizer compiling beautiful PDFs and Excel databases.

  • Table reports exported to PDF & Excel.
  • WYSIWYG letterhead docs with {field} placeholders.
  • DomPDF & Maatwebsite Excel export engine.
  • Allowlisted data sources — no SQL required.
php artisan larakit:install reports
Extension

Database Backup

On-demand & scheduled backups powered by spatie/laravel-backup.

  • Database-only or database + files snapshots.
  • Private storage with retention & auto-cleanup.
  • One-click download & full run history.
  • Every run captured in the Activity Log.
php artisan larakit:install backup
Registry

One registry, every module

Modules resolve from the LaraKit registry with checksum verification, version pinning and dependency checks before they ever touch your app.

php artisan larakit:install --list
Included in the core

Batteries Included by Default

Every install ships with the plumbing every SaaS needs — auth, roles, audit trails and i18n — wired into a clean modular architecture.

Auth + Google OAuth

Laravel Breeze (Blade) login, registration and password reset, plus one-click Google sign-in via Socialite.

Roles & Permissions

Granular RBAC backed by spatie/laravel-permission, seeded with SuperAdmin, Admin and User roles out of the box.

Realtime Activity Log

Every model and controller action audited via spatie/activitylog and broadcast live over Laravel Reverb WebSockets.

Dynamic Menu Builder

Database-driven sidebar menus with nesting, ordering and per-role visibility — no hard-coded navigation.

Multi-language (i18n)

English & Indonesian out of the box with localized routes powered by mcamara/laravel-localization.

Settings & DataTables

A central settings store plus server-side Yajra DataTables and Intervention Image handling, ready to use.
