Frequently Asked Questions

Everything you need to know about the product and billing.

// general

What exactly is LaraKit? LaraKit is a Laravel 13 modular SaaS starter kit. It bundles the Butunix admin dashboard, a glassmorphism landing page, authentication, roles & permissions, realtime activity logging and seven installable feature modules — so you start from a working product, not an empty composer create-project.

Can I use LaraKit for commercial projects? Yes. With a Pro or Enterprise license you can build and sell unlimited SaaS applications to your clients with no royalty fees. The Starter license covers a single project.

Who is LaraKit built for? Indie hackers shipping an MVP, agencies spinning up client projects, and startups that want production-grade auth, RBAC and audit logging without rebuilding it every time.

// technical

Do I need to know Laravel? LaraKit handles the boilerplate, but you should be comfortable with Laravel fundamentals — routing, Eloquent and Blade — to add your own business logic.

What's the underlying tech stack? PHP 8.3 + Laravel 13.7, Breeze for auth, Socialite for OAuth, spatie/laravel-permission & activitylog, mcamara/laravel-localization, Yajra DataTables and Intervention Image. The UI runs on Bootstrap 5.3 with Vite, and realtime features use Laravel Reverb.

How is the codebase structured? Everything lives under a modular architecture in app/Modules/Core. Each feature keeps its own controllers, models, routes, views and language files, so modules stay isolated and easy to reason about.

Which databases are supported? MySQL 8 is the default, but because everything uses Eloquent and migrations you can switch to PostgreSQL or SQLite with a config change.

// modules

How do I install a module? Run php artisan larakit:install <module>. LaraKit resolves it from the registry, verifies the checksum, then copies files and runs the module's migrations and seeders automatically.

Which modules are available? Seven: Storage Manager, Email Manager, AI Assistant & Knowledge Base, Notification Manager, WA Gateway, Report Builder and Database Backup — all included with Pro and Enterprise.

Which AI providers does the AI module support? Anthropic, OpenAI, Gemini, Groq and local Ollama models — with customizable assistants, a RAG knowledge base and an embeddable chat widget.

Does WhatsApp require a paid API? No. The WA Gateway is a self-hosted WhatsApp engine with real-time SSE, multi-device support and auto session recovery. It plugs into the Notification Manager as a delivery provider.

// licensing & support

Are updates included? Pro and Enterprise include free lifetime updates for the LaraKit core and modules. Starter includes one year of updates.

Is this glassmorphism layout included? Yes — the exact landing page you're reading ships with the Pro and Enterprise plans as a starting point for your marketing site.

How do I get support? Email support is included on every plan, with priority response on Pro (6 months) and Enterprise (1 year). You also get full documentation and access to the community.

What is your refund policy? If LaraKit isn't the right fit, email us within 14 days of purchase for a full refund — no questions asked.
